Какие данные собираются

При использовании сайта автоматически собираются технические события: просмотр страницы, запуск игры, выбранная сложность, прохождение заданий и этапов, примерная категория устройства, операционная платформа и браузер. Для объединения событий одного браузера используется случайный псевдонимный ID, а для группировки действий — ID игровой сессии. Также учитываются текущий этап и активность видимой вкладки. При технической ошибке сохраняется только её тип, без текста и стека.

Мы не запрашиваем имя, контакты или ответы на задания и не сохраняем их. IP-адрес не записывается в таблицы аналитики; Cloudflare может обрабатывать технические данные запросов для работы своей инфраструктуры.

Зачем это нужно и кто обрабатывает данные

Статистика используется для оценки посещаемости, работы игровых этапов и технического качества проекта. Данные обрабатываются в базе Cloudflare D1; администратор проекта просматривает сводную статистику и псевдонимные профили устройств через закрытую Telegram-панель. Эти данные не предназначены для установления личности посетителей.

Срок хранения

События, игровые сессии и технические уведомления удаляются примерно через 180 дней. Профиль браузера удаляется после 180 дней без новых посещений.

Уведомление на сайте

Кнопка «Понятно» закрывает уведомление и запоминает это решение в текущем браузере. Она не отключает сбор технической статистики.

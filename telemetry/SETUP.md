# Статистика игры и Telegram-бот администратора

Сервис состоит из Cloudflare Worker и базы данных D1. Игра отправляет аналитику
автоматически, если в `js/telemetry-config.js` указан адрес развёрнутого Worker.
Краткое уведомление показывается один раз в каждом браузере до нажатия «Понятно»;
после этого оно исчезает и больше не открывается. Телеметрия работает независимо
от нажатия этой кнопки.

## Какие данные собираются

- Случайный псевдонимный ID браузера, который хранится в localStorage и
  связывает статистику этого браузера между визитами. Отдельная сессия вкладки
  обновляется после 30 минут бездействия. ID не содержит имени и не связывает
  разные браузеры или устройства.
- Просмотры страниц «Главная» и «Игра», примерная категория устройства,
  операционная платформа и название браузера, выбранная сложность, ID пройденных
  заданий и локаций, набранные баллы, текущая страница и этап, а также сигнал
  активности видимой вкладки раз в минуту для приблизительной оценки онлайна.
  Сохраняется только тип JavaScript-ошибки (без текста ошибки и стека).
- Worker не сохраняет имена, контакты, ответы, текст ошибок или цифровой
  отпечаток браузера. IP не записывается в таблицы статистики; Cloudflare может
  обрабатывать технические метаданные запросов в рамках своей инфраструктуры.
- События, уведомления и сессии автоматически удаляются примерно через
  180 дней. Сводный профиль браузера удаляется после 180 дней без новых
  посещений.
- Статистика нужна для контроля качества игры и администрирования; уведомление
  можно закрыть, но интерфейс игры не предоставляет отключение телеметрии.

## 1. Создайте Worker и базу данных

Откройте PowerShell в папке `telemetry` проекта. Потребуется аккаунт Cloudflare
и установленный Node.js. Войдите в Cloudflare и создайте D1-базу:

```powershell
npx.cmd wrangler login
npx.cmd wrangler d1 create scv-telemetry
```

В ответ Cloudflare покажет ID базы. Откройте `telemetry/wrangler.toml` и:

1. Замените `REPLACE-WITH-D1-DATABASE-ID` на выданный ID.
2. Замените `https://REPLACE-WITH-YOUR-SITE-ORIGIN` на точный адрес сайта,
   например `https://example.com`. Укажите только схему и домен: без пути и
   завершающего `/`. Не используйте адрес локального сервера — нужен именно тот
   адрес, который открывают игроки.

Создайте таблицы в удалённой D1-базе. Команду выполняйте из папки `telemetry`:

```powershell
npx.cmd wrangler d1 execute scv-telemetry --remote --file=./schema.sql
```

## 2. Отзовите старый токен и задайте секреты бота

Токен, который был отправлен в чат, необходимо считать скомпрометированным.
Отзовите его через BotFather и создайте новый. Не отправляйте новый токен в чат,
не записывайте его в файлы проекта и не добавляйте в Git.

Добавьте секреты в Cloudflare командой ниже. Wrangler запросит значение в
терминале — вставляйте секрет только в этот запрос:

```powershell
npx.cmd wrangler secret put TELEGRAM_BOT_TOKEN
npx.cmd wrangler secret put TELEGRAM_ADMIN_ID
npx.cmd wrangler secret put WEBHOOK_SECRET
```

При запросе:

- `TELEGRAM_BOT_TOKEN` — введите новый токен, выданный BotFather.
- `TELEGRAM_ADMIN_ID` — введите свой числовой Telegram ID. Только этот аккаунт
  сможет получать отчёты и отправлять команды боту.
- `WEBHOOK_SECRET` — задайте длинную случайную строку из латинских букв, цифр,
  `_` или `-`. Сохраните её в менеджере паролей: она понадобится на следующем
  шаге.

Разверните Worker:

```powershell
npx.cmd wrangler deploy
```

Сохраните адрес Worker, который появится в выводе, например
`https://scv-telemetry.<ваш-поддомен>.workers.dev`.

## 3. Подключите Telegram webhook

Сначала откройте чат с ботом в Telegram и нажмите **Start**. Telegram не
разрешает боту первым начинать личный разговор.

Затем выполните в PowerShell следующий блок. Он запросит токен и секрет
вебхука скрытым вводом и не сохраняет их в файле:

```powershell
$botSecure = Read-Host "Новый токен бота" -AsSecureString
$hookSecure = Read-Host "Секрет вебхука (WEBHOOK_SECRET)" -AsSecureString
$bot = [System.Net.NetworkCredential]::new("", $botSecure).Password
$hook = [System.Net.NetworkCredential]::new("", $hookSecure).Password
$body = @{ url = "https://YOUR-WORKER.workers.dev/telegram"; secret_token = $hook } | ConvertTo-Json
Invoke-RestMethod -Uri "https://api.telegram.org/bot$bot/setWebhook" -Method Post -ContentType "application/json" -Body $body
Remove-Variable bot, hook, botSecure, hookSecure
```

В строке URL замени `https://YOUR-WORKER.workers.dev` на адрес Worker из шага 2.
Введи те же токен и `WEBHOOK_SECRET`, которые только что сохранил в Cloudflare.
В успешном ответе Telegram будет `"ok": true`.

## 4. Включите сбор статистики в игре

Откройте `js/telemetry-config.js` и укажи адрес Worker для событий:

```js
window.SCV_TELEMETRY_ENDPOINT = 'https://YOUR-WORKER.workers.dev/api/events';
```

Здесь замени `https://YOUR-WORKER.workers.dev` на свой адрес Worker. Этот адрес
публичный и не является секретом. **Не добавляй сюда токен бота,
`WEBHOOK_SECRET` или Telegram ID администратора.**

Проверь, что адрес `https://YOUR-WORKER.workers.dev/health` возвращает
`{"ok":true}`. После этого опубликуй обновлённые файлы игры на сайте. События
отправляются автоматически; игрокам показывается уведомление, которое можно
закрыть без отключения сбора.

Перед публичным запуском добавь в Cloudflare правило ограничения частоты
запросов к `/api/events`, чтобы снизить риск автоматического спама.

### Обновление профиля устройства

Если в удалённой D1-базе ещё нет колонок `device_type`, `platform_name` и
`browser_name`, примени миграцию один раз из папки `telemetry`:

```powershell
npx.cmd wrangler d1 execute scv-telemetry --remote --file=./migrations/0003_device_profile.sql
```

После этого разверни Worker и опубликуй файлы сайта. Бот показывает PNG-сводку
по команде `/start` или `/stats`; кнопка «Игроки» открывает список браузеров
страницами по пять записей, а кнопка браузера — его статистику, последние
сессии и события. В изображениях устройства обозначаются краткими категориями;
уникальный анонимный ID остаётся доступен только в админском чате.

## 5. Обновление уже развёрнутого сервиса

Если миграция 0002 уже применена, пропусти её. Если в удалённой базе ещё нет
профиля устройств, выполни обе миграции из папки `telemetry` в указанном порядке:

```powershell
npx.cmd wrangler d1 execute scv-telemetry --remote --file=./migrations/0002_session_presence_and_stage.sql
npx.cmd wrangler d1 execute scv-telemetry --remote --file=./migrations/0003_device_profile.sql
npx.cmd wrangler deploy
```

Миграция 0002 добавляет в сессии текущую страницу и этап прохождения; 0003 —
категорию устройства, платформу и браузер в профиле браузера. Не запускай уже
применённую миграцию повторно. Повторно задавать Telegram secrets или
регистрировать webhook не нужно.

Открой личный чат с ботом и отправь `/start`, `/stats` или `/menu`: бот пришлёт
изображение с общей статистикой и кнопками разделов.

- `/stats` — общие просмотры, число анонимных браузеров, запуски игры,
  завершённые задания и локации, активность за последние 24 часа и количество
  недавних ошибок, с кнопками для подробностей.
- **Онлайн** — число браузеров с активной вкладкой за последние 2 минуты и
  открытые страницы/этапы. Это приблизительная оценка.
- **Этапы** — сколько раз завершали локации и сколько игроков сейчас находится
  на каждом этапе.
- **Сложность** — запуски и активные игроки по выбранной сложности.
- **Игроки** или `/users` — полный список браузеров, по пять на страницу;
  кнопка устройства открывает его профиль и постраничную историю событий.
- `/user <начало ID>` — профиль браузера по ID из кнопки или подписи списка.
- `/errors` — последние типы технических ошибок без текста ошибки и стека.

Бот отвечает только на личные сообщения от указанного `TELEGRAM_ADMIN_ID`.
